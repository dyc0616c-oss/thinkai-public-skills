# 排班计划助手

用于根据人员、班次、请假和休息要求生成排班表，并提前发现冲突。

## 你可以这样说

```text
根据这份人员名单和可上班时间，安排下周早中晚班。
```

```text
检查这张排班表有没有连续工作过久、重复排班或缺人的情况。
```

```text
在不改变请假安排的前提下，让每个人的班次数量尽量公平。
```

## 它会做什么

- 生成一份待确认的排班草案；
- 检查人员冲突、缺岗和休息不足；
- 统计每个人的班次数量；
- 对无法同时满足的要求给出替代方案。

## 安装

```bash
npx skills add https://github.com/dyc0616c-oss/shift-schedule-planner
```

## 使用提醒

排班结果必须由负责人确认后再发布。劳动时间、休息和特殊岗位要求应以当地规定及公司制度为准。
