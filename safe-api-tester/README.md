# 安全 API 测试器

一次检查多个接口是否正常，并生成一份容易查看的测试报告。

## 它能解决什么问题

当网站、应用或内部工具依赖多个接口时，逐个打开检查很费时间。这个 Skill 可以按照你提供的测试清单依次检查，并告诉你：

- 哪些接口运行正常；
- 哪些接口返回了错误；
- 实际结果是否符合预期；
- 测试中是否出现需要隐藏的敏感信息。

它适合上线前检查、日常巡检和问题排查。

## 你可以这样使用

安装：

```bash
npx skills add https://github.com/dyc0616c-oss/safe-api-tester
```

然后直接对 Agent 说：

```text
帮我检查本地项目的接口是否正常，并生成测试报告。
```

```text
根据这份接口清单逐项测试，只执行安全的读取操作。
```

```text
检查测试报告里哪些接口失败了，并用中文总结原因。
```

Agent 会先确认测试目标和授权范围，再执行检查。

## 适合谁

- 需要检查网站或应用接口的开发者；
- 需要做上线验收的产品和测试人员；
- 希望快速获得一份接口检查报告的小团队。

## 安全提醒

- 默认只执行不会修改数据的读取检查；
- 默认只访问本机或你明确允许的地址；
- 不提供攻击、撞库或漏洞利用功能；
- 只能测试你拥有或已经获得授权的接口。
