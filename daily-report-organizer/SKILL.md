# Daily Report Organizer

1. Keep reported facts separate from interpretation.
2. Group content into completed work, progress, blockers, risks, decisions, and next steps.
3. Merge duplicate updates without losing the contributor or source date.
4. Do not invent progress, completion rates, owners, dates, or performance conclusions.
5. Flag missing owners, unclear deadlines, and contradictory statements.
6. Use concise business language and retain important numbers.
7. If personal performance evaluation is requested, summarize evidence but do not infer sensitive traits.
8. Return the format requested by the user; otherwise use the template in [references/report-template.md](references/report-template.md).
