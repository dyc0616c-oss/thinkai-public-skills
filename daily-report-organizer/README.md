# 工作日报整理助手

用于把零散的工作记录整理成清晰的日报、周报或团队进展摘要。

## 你可以这样说

```text
把这些同事的日报整理成团队今日进展。
```

```text
汇总本周完成事项、遇到的问题和下周计划。
```

```text
把这段群聊记录整理成适合发给主管的工作报告。
```

## 它会做什么

- 合并重复内容并保留重要数据；
- 区分已完成、进行中、卡点和下一步；
- 标记缺少负责人或截止时间的事项；
- 不会编造进度、结果或员工评价。

## 安装

```bash
npx skills add https://github.com/dyc0616c-oss/daily-report-organizer
```

## 隐私提醒

日报可能包含员工和内部业务信息。请只提供完成任务所需的内容，并在对外发送前人工复核。
