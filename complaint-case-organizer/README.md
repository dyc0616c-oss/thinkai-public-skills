# 投诉处理整理助手

用于把零散投诉整理成清晰的案件记录，方便分类、分派和持续跟进。

## 你可以这样说

```text
把这些投诉信息整理成案件清单，并标出缺少的资料。
```

```text
按照紧急程度对投诉分类，给出下一步处理建议。
```

```text
汇总本月重复出现的投诉问题，找出需要优先改善的环节。
```

## 它会做什么

- 整理客户诉求、时间、问题类型和处理状态；
- 标记重复投诉、缺失材料和临近期限；
- 生成中立的回复草稿和跟进清单；
- 汇总高频问题，帮助团队复盘。

## 安装

```bash
npx skills add https://github.com/dyc0616c-oss/complaint-case-organizer
```

## 安全提醒

它不会自动退款、封号、联系客户或操作任何后台。涉及个人信息时，应只保留处理投诉所需的最少数据。
