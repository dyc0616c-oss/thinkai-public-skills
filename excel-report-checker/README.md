# Excel 报表检查助手

用于检查一份 Excel 报表是否有异常，或者比较两份报表有哪些变化。

## 你可以这样说

```text
检查这份销售报表有没有重复、缺失或合计错误。
```

```text
比较新旧两份员工名单，告诉我新增、删除和修改了哪些人。
```

```text
以订单号为准对比两份报表，并生成一份差异结果。
```

## 它会做什么

- 识别重复、缺失、格式异常和明显错误；
- 比较新增、删除和修改的数据；
- 对无法确定的匹配标记“需要确认”；
- 生成新的结果文件，不覆盖原始 Excel。

## 安装

```bash
npx skills add https://github.com/dyc0616c-oss/excel-report-checker
```
