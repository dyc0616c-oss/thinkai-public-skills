# FAQ 内容优化助手

用于把难懂、重复或不统一的常见问题，整理成更清楚的标准问答。

## 你可以这样说

```text
把这批客服问答改得更简洁、礼貌，意思不能改变。
```

```text
为每条 FAQ 生成几种用户可能使用的相似问法。
```

```text
检查这份知识库里有没有重复或互相矛盾的回答。
```

## 它会做什么

- 优化问题标题和标准回答；
- 生成相似问法和搜索词；
- 标记重复、冲突和需要核实的内容；
- 整理成方便审核和导入的表格结构。

## 安装

```bash
npx skills add https://github.com/dyc0616c-oss/faq-content-optimizer
```

## 使用提醒

它不会自动连接客服后台或发布话术。涉及价格、退款、资格和政策的回答，上线前必须由业务负责人确认。
